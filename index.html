/ 02 — projects

Featured work.

A deep dive into the project I shipped most recently — covering the architecture, the engineering decisions, and the trade-offs.

StayEase

Full-stack hotel booking platform with AI chatbot

Live site GitHub

StayEase is a commission-free hotel booking and management platform built as my B.Tech major project. It gives independent hotel owners a place to list properties and lets guests search, filter, and pay in real time — all backed by a webhook-driven architecture and a custom availability engine.

Real-time availability

Custom date-overlap algorithm prevents double-booking by checking ranges before every reservation.

Stripe + Pay-at-Hotel

Webhook-confirmed Stripe Checkout (INR) alongside a fallback offline payment flow for guests.

Clerk authentication

Email/password and Google OAuth, with Svix-verified webhooks syncing user state to MongoDB.

Rule-based AI chatbot

Regex-driven NLP layer parses queries by city, price, room type, amenities, and sort intent.

Owner dashboard

Aggregated revenue, total bookings, and recent activity computed via Array.reduce server-side.

Cloudinary + Brevo SMTP

Parallel image uploads via Promise.all and HTML booking confirmation emails on every payment.
